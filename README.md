# Product List Manager
##Description
A simple application for managing products by storing them in a list.
## Features
- Simple to use interactive interface
- Persistence, can save a list to a .json file and restore it on startup
## Technologies
- .NET
- C#
- LINQ
- JSON
## Installation
Clone the repository and build the project in the sub folder "\Product List Manager" with the command:
`msbuild "Product List Manager.csproj" -p:Configuration=Release`
For some reason I got an error message when testing and had to run `dotnet restore` first.

The resulting executable will be under "\bin\Release\net10.0\".

## How to run
Just run the executable "Product List Manager.exe". And follow the instructions
